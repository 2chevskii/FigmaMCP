# Support

Thank you for using Figma MCP. Before asking for help, review the [README](README.md), the
[documentation](docs/), and the [existing issues](https://github.com/2chevskii/FigmaMCP/issues).

## Ask a question

Open a [GitHub issue](https://github.com/2chevskii/FigmaMCP/issues/new) for installation,
configuration, and usage questions. Include your operating system, Figma Desktop version, Figma MCP
version or commit, installation method, and the exact error or diagnostic output. Remove secrets and
personal data before posting.

## Report a bug or request a feature

Open an issue for reproducible defects and proposed changes. For bugs, include the smallest
reproduction you can provide and distinguish server diagnostics on `stderr` from MCP protocol
messages on `stdout`.

## Security vulnerabilities

Do not report suspected vulnerabilities in a public issue. Follow the private reporting process in
the repository's [security policy](.github/SECURITY.md).

## Scope

Support is provided on a best-effort basis. General Figma product support, third-party MCP client
support, and custom integration consulting are outside this project's support scope unless the
problem is caused by Figma MCP.
